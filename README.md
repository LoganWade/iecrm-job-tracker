# IECRM Job Tracker

A modern, fast React application for tracking job applications to the **IECRM Electrical Contractor List** (219 companies).  
**Heavy focus on Fort Collins / Northern Colorado + AI/Data Center relevant employers.**

## ✨ Features

- Full 219-company database from your IECRM spreadsheet
- Smart prioritization: Northern CO + AI/Data Center companies at the top
- Interactive Dashboard with live stats
- Powerful searchable & filterable Companies table (distance, AI relevance, score, etc.)
- Complete Applications Tracker (add/edit/delete, status pipeline, recruiter notes)
- All data saved in browser (localStorage) — no backend needed
- Clean modern dark UI, fully responsive

## 🚀 Quick Start (Local Development)

### 1. Clone the repository
```bash
git clone https://github.com/loganwade/iecrm-job-tracker.git
cd iecrm-job-tracker

npm install

npm run dev
```
